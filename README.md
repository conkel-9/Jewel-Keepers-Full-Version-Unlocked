## Overview
<a id="overview"></a>

Jewel Keepers is an engaging puzzle game designed for Windows users, where players embark on an adventurous quest to uncover the lost treasure of Easter Island. The game requires players to match three or more identical jewels in a line, much like classic titles in the genre. Unlike traditional match-3 games, Jewel Keepers adds the challenge of turning all squares into gold to complete each level. This unique twist sets it apart from typical alternatives in the market.
